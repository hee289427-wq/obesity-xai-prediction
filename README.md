# Obesity XAI Prediction

An explainable obesity-level prediction web application using Random Forest, SHAP waterfall explanations, and what-if counterfactual analysis.

## Files required

- `app.py`
- `requirements.txt`
- `.python-version`
- `ObesityDataSet_raw_and_data_sinthetic.csv`

## Render settings

- Service type: Web Service
- Runtime: Python 3
- Build command: `pip install -r requirements.txt`
- Start command: `python app.py`
- Instance type: Free

The app binds to Render's `PORT` environment variable on `0.0.0.0`.
